Galería y Gráficos Interactivos

Un proyecto web que combina una galería dinámica de imágenes y gráficos interactivos. Diseñado con Bootstrap, JavaScript y ApexCharts.

Galería de Imágenes

Selecciona la cantidad de imágenes que deseas mostrar en la galería. Las imágenes se cargan dinámicamente desde Picsum.photos.

Gráficos Interactivos

Explora los datos a través de gráficos dinámicos. Cambia el conjunto de datos para ver cómo se actualizan los gráficos en tiempo real.
